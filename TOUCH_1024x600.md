# Interface tactile 1024 × 600 — V3

- **Accueil** `/monitor` : les quatre indicateurs principaux, les cinq modes et les commandes déjà présentes dans la V2 ; CSS compact si la hauteur de fenêtre est ≤ 650 px et largeur ≥ 850 px.
- **Manuel** `/oldstyle` : LCD et les six boutons d’origine conservés, durée `short` / `normal` / `long`, envoi immédiat comme auparavant. Aucun bouton n’a été renommé côté TypeScript.
- **Statistiques** `/stats` : historiques de la V2 avec adaptation des cartes. Sur une hauteur de 600 px, les graphiques peuvent défiler : préserver leur lisibilité prime sur la suppression du scroll.
- **Configuration** `/config` : route et logique conservées.

## Attention à l’API de commandes

Le service source contenait `sendCommand(command)` mais appelait `http://localhost/pellets/command.json` sans la chaîne demandée. La V3 ajoute `?` + `command` pour restaurer la transmission. Vérifier le chemin réel du proxy en production : `localhost` dans un navigateur distant désigne la machine cliente, et non le serveur du poêle. Les appels `refreshInfo()` et `sendCommand()` ont été volontairement conservés sur la même origine que la V2 pour ne pas inventer de chemin de production.

## Vérification avant déploiement

Tester visuellement Chrome en 1024 × 600 et en mobile ; valider avec l’appareil réel le mapping des boutons (surtout les combinaisons), les modes, la sélection des durées et la réponse du backend. Aucun test matériel ni build Angular n’a été exécuté ici.
